# Branch Practice Project

This project is a simple Git practice repository made for learning how branching works in a real development workflow.

## Purpose

The main goal of this project is to help you practice and understand:

- creating and switching branches
- making commits on different branches
- merging feature work back into the main branch
- resolving simple merge conflicts
- keeping a clean and organized Git history

## What This Project Is For

Use this repository as a sandbox to explore Git workflows without the pressure of a production project. You can create new branches, add changes, and merge them back to practice the everyday commands developers use.

## Typical Workflow

A common exercise with this project is:

1. Start on the main branch
2. Create a feature branch
3. Make a few commits on that branch
4. Merge the branch into main
5. Resolve conflicts or fix mistakes
6. Clean up completed branches

## Learning Goals

By using this project, you should become more comfortable with:

- branch creation and navigation
- isolated work on separate branches
- commit history and branch tracking
- merge operations
- handling simple Git conflicts

## Getting Started

Clone the repository and begin with basic Git commands:

```bash
git status
git branch
```

Create a new branch:

```bash
git checkout -b feature/my-change
```

Or use the newer command:

```bash
git switch -c feature/my-change
```
